# Хроніки Слова — Android-проєкт

Навчальна пригодницька гра українською мовою. Проєкт підготовлено як основу звичайного Android-застосунку: він має назву, адаптивну іконку, стартовий екран, темну тему та окремі debug/release-конфігурації.

## Що є в цій версії 0.2.0

- Kotlin + Jetpack Compose + Material 3
- головні вкладки: Світ, Герой, Архів
- карта шести регіонів і стартова місія
- початкові картки правил та тренувальні вправи
- локальне збереження XP і статистики через Room
- базові модулі адаптивної складності, досвіду та повторення
- адаптивна іконка застосунку та стартовий екран Android
- обробка системної кнопки «Назад» під час вправи
- конфігурація окремих debug і release-збірок

## Як отримати APK

Потрібні Android Studio, JDK 17 та Android SDK 35.

1. Розпакуйте архів.
2. В Android Studio оберіть **Open** і відкрийте папку `ChroniclesOfWords`.
3. Дочекайтеся Gradle Sync. Якщо Android Studio запропонує встановити відсутні компоненти SDK, погодьтеся.
4. Для тестової встановлюваної версії відкрийте **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK буде створено в `app/build/outputs/apk/debug/`. Файл `app-debug.apk` можна перенести на телефон і встановити.

Для релізного APK використовуйте варіант **release**. Для Google Play потрібен Android App Bundle (AAB): **Build → Generate Signed Bundle / APK → Android App Bundle**. Підпишіть реліз власним ключем і збережіть його резервну копію в безпечному місці.

### Зібрати APK без Android Studio через GitHub

У проєкті є workflow `.github/workflows/android-build.yml`:

1. Створіть порожній репозиторій на GitHub.
2. Завантажте в нього вміст папки `ChroniclesOfWords`.
3. Відкрийте вкладку **Actions** у репозиторії.
4. Запустіть **Build Android APK** через **Run workflow** або дочекайтеся автоматичної збірки після push у `main` чи `master`.
5. Після успішної збірки відкрийте її сторінку та завантажте артефакт `chronicles-of-words-debug-apk`.
6. Розпакуйте завантажений артефакт. Усередині буде APK для встановлення на Android.

> У цьому середовищі немає Android SDK та Gradle, тому APK/AAB тут не збирався. Архів містить вихідний Android-проєкт і сценарій автоматичної збірки, а не готовий інсталяційний файл.

## Нормативна база

Контент у `GameContent.kt` є демонстраційним стартовим набором, а не повним курсом. Перед публічним релізом кожне правило та завдання слід звірити з офіційним стандартом і перевірити редакторськи.

Український правопис. Офіційне видання, 2026:
https://comin.gov.ua/storage/app/sites/33/standarty-movy/sdm-ukrayinskii-pravopis-oficiine-vidannia-2026.pdf

## Що ще треба завершити до публікації

- довести навчальну базу до повноцінного курсу та перевірити всі відповіді;
- пов'язати адаптивний рушій і календар повторень із прогресом Room;
- додати повний сюжет першої глави, нагороди та завершення місії;
- протестувати на реальних Android-пристроях різних розмірів;
- підготувати політику конфіденційності, графіку сторінки магазину та підписаний AAB;
- виконати вимоги Google Play щодо тестування й публікації.

Це оновлена основа застосунку, не завершений реліз і не підтверджений APK.
